Each artwork PNG is **2048 × 2048 pixels**. The comparisons are smaller review images. The PNGs contain artwork without labels; the contact sheets carry names and descriptive captions.

| Family | Structure | Circular elements | Main colour mixture |
|---|---|---|---|
| Circuit | Six stepped circuit assemblies | Two segmented framing rings | Cyan / cobalt / silver |
| Lightning | Three irregular jagged branching bolts | One broken halo | Amber / orange / icy white |
| Coral | Four flowing arms with rounded forks | Three fine framing halos | Violet / turquoise / pink |
| Frost | Eight needle-like crystal arms | One fine enclosing circle | Ice blue / silver / lavender |
| Roots | Asymmetric tapered spreading roots | One offset framing halo | Emerald / teal / gold |
| Trident | Three heavy assemblies, nine prongs | Three prominent circular junctions | Scarlet / titanium / amber |
| Crown | Upward branching fan, low central core | One open halo | Gold / indigo / warm white |
| Lattice | Four diagonal assemblies with cross-bracing | Four circular junctions; no framing ring | Cobalt / violet / cyan |
| Cascade | Curving hanging branches, high core | Two offset open halos | Silver / turquoise / midnight blue |
| Bonsai | One curved trunk and asymmetrical canopy | One framing circle and seven golden fruit orbs | Copper / jade / gold |
| Starburst | Twelve rays with alternating reach | Three segmented concentric rings | Rose gold / sapphire / pearl |

The group differences are built into the geometry, composition, branch construction, ring placement, and node arrangement. Each family also has a distinct three-colour palette. Tiny fastening collars and decorative hub bands are not counted as framing rings in this table.

## Review sequence

1. Review the eleven proposed family identities.
2. Develop visibly different individual compositions within the selected families.
3. Review representative Motion and Volumetric animations using the selected geometry.
4. Render the revised 198-artwork collection after those comparisons meet the owner's expectations.

The planned quantities remain 99 Preview, 66 Motion, and 33 Volumetric. The animation distinction remains slow structural motion for Motion, and clear foreground/rear separation and merging for Volumetric.

This review package contains PNG stills. It does not contain the revised GIF collection. Family names and the final per-artwork ID assignment remain subject to review.

## Optional reproducibility files

The ZIP includes geometry JSON, the renderer, geometry generators, a manifest and a validation report. Rendering uses Python, NumPy and Pillow. The dimensional appearance is created by bevelled rails, shaded spheres, extrusion edges and controlled light spill; Blender is not required.

To reproduce the representative stills in an environment with NumPy and Pillow installed:

    python source/render_review.py

The current geometry generators establish the eleven representative designs. The final per-artwork variation system will be developed in the next review stage; its existing variant parameters should not be treated as final approval for all 198 compositions.

The previous 198-artwork collection remains available separately. These are new design-review files and no NFTs have been minted or published on OpenSea from this review set.
