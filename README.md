# Forge Pass — 11 family samples

[Download the sample ZIP (98.6 MB)](https://github.com/aygaladima/New/raw/refs/heads/forge-pass-11-family-samples/ForgePass_11_Family_Samples.zip)

Contains **11 Preview PNGs + 11 Volumetric GIFs**, one of each per family.

The original approved artwork files are preserved: PNGs at 2048 × 2048, GIFs at 1000 × 1000, 20 fps, 12-second infinite loops. Extract the ZIP and open the GIFs in an animation-capable viewer or browser.

[View the labeled comparison sheet](Family_Samples_Overview.jpg). The comparison sheet shows still poses; the GIF files contain the animations.

Each family folder contains two different artwork samples. Original artwork IDs and SHA-256 values are recorded in Sample_Inventory.json inside the ZIP. These are samples from the finished 1,100-artwork edition.
